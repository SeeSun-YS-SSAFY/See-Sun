## 1. 축과 표기

| 축 | 값 | 어떻게 만들었나 |
|---|---|---|
| 입력 | 버튼 · 음성 · 키보드 · TalkBack | 버튼·키보드는 Compose 시험 동작(접근성 동작 경로), 음성은 에뮬레이터에 한국어 인식기가 없어 **인식 불가 대체 경로**만 실서버, 실제 음성 해석은 기능 기기 시험(대본 인식기), TalkBack은 `settings put secure enabled_accessibility_services …TalkBackService`로 켬 |
| 네트워크 | 정상 · 오프라인 · 서버 5xx · 시간 초과 | 오프라인 = 프록시 `reset`(연결 끊김) + `svc wifi/data disable`, 5xx = 프록시가 운영 Django와 같은 HTML 500 본문, 시간 초과 = 프록시 `hang 25초`(앱 제한 20초) |
| 수명 주기 | 회전 · 백그라운드↔포그라운드 · 프로세스 종료 | `requestedOrientation`, `ActivityScenario.moveToState`, `am kill`(백그라운드 정리) / `am crash`(비정상 종료) |
| 데이터 상태 | 신규 · 기존 회원 · 동의 철회(민감정보) · 동의 문서 변경 · 탈퇴 계정 · 토큰 만료 | 서버 DB에 이용약관 새 버전을 올려 문서 변경, 토큰은 debug 전용 `DebugTestEntryPoint`로 앱 싱글턴에 만료·거절 값을 심음 |
