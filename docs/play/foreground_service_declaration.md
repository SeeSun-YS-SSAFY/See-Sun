# 포그라운드 서비스 선언(Play Console) — 운동 안내 음성

> 법률 검토 구현 보완 P-13 · 2026-10-12 · 대상 빌드: 시선 Android(`kr.seesun.app`) targetSdk 36

## 1. 앱이 쓰는 포그라운드 서비스

| 항목 | 값 |
|---|---|
| 서비스 | `kr.seesun.feature.exercise.session.ExerciseSessionService`(feature:exercise 모듈 매니페스트) |
| 유형 | `android:foregroundServiceType="mediaPlayback"` |
| 권한 | `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_MEDIA_PLAYBACK`, (휴식 타이머용) `WAKE_LOCK` |
| 시작 | 사용자가 운동 화면에서 **[재생]** 또는 **[루틴 시작]**을 누를 때(앱이 화면에 떠 있는 상태) |
| 끝 | [운동 마치기]·[루틴 끝내기]·나가기, 또는 운동 화면이 닫힐 때 즉시 `stopService` |
| 알림 | "운동 중: (운동 이름)" — 소리 없는 진행 알림, 누르면 운동 화면으로 |
| 재생 방식 | Media3 ExoPlayer + MediaSession(이어폰 버튼). Media3 `MediaSessionService`는 쓰지 않고, 위 서비스가 앱 프로세스를 살려 둔다 |

**왜 필요한가:** 시각장애 사용자는 화면을 끄거나 잠근 채 운동 안내 음성을 듣는다. 안드로이드 14 이상은 화면이 꺼진 백그라운드 앱을 얼려(cached app freezer) 소리와 휴식 타이머가 멈추므로, 사용자가 시작한 운동 안내 재생 동안에만 미디어 재생 포그라운드 서비스를 쓴다. 에뮬레이터 QA에서 화면을 45초 끈 동안 루틴 안내가 1구간 → 3구간으로 이어지는 것을 확인했다.

## 2. Play Console 선언 문구(앱 콘텐츠 → 포그라운드 서비스 권한)

- **유형:** 미디어 재생(Media playback)
- **기능 설명(붙여 넣을 문구):**

> 시선은 시각장애·저시력 사용자를 위한 운동 안내 앱입니다. 사용자가 운동 화면에서 재생 버튼이나 루틴 시작 버튼을 누르면, 운동 동작을 설명하는 안내 음성(오디오 파일 또는 기기 음성)을 재생하고 운동 사이 휴식 시간을 세어 알려 줍니다. 사용자는 화면을 보지 않고 휴대폰을 주머니에 넣거나 화면을 끈 채 운동하므로, 화면이 꺼진 동안에도 안내 음성과 휴식 안내가 끊기지 않도록 미디어 재생 포그라운드 서비스를 사용합니다. 서비스는 사용자가 재생을 시작할 때만 켜지고, 운동을 마치거나 화면을 나가면 바로 꺼집니다. 진행 중에는 "운동 중" 알림이 표시되며, 이어폰 버튼·일시정지 버튼으로 언제든 멈출 수 있습니다.

- **사용자에게 미치는 영향(지연·중단 시):** 서비스를 쓰지 못하면 화면이 꺼진 뒤 안내 음성이 중간에 끊겨, 화면을 볼 수 없는 사용자가 운동 동작·휴식 시간을 알 수 없게 된다.

## 3. 데모 동영상에 담을 장면(30초~1분, 세로 화면 녹화)

1. 앱 실행 → 메인 [운동] → [한 가지 운동] → [근력 운동] → [맨몸 스쿼트] (또는 [루틴 운동] → [근력 운동 루틴] → [루틴 시작]).
2. **[재생]을 누르는 순간**이 보여야 한다(사용자가 직접 시작한다는 증거).
3. 상단 상태 표시줄·알림 창을 내려 **"운동 중: 맨몸 스쿼트" 알림**이 떠 있는 것을 보여 준다.
4. 전원 버튼으로 **화면을 끄고**(녹화는 외부 카메라 또는 화면 녹화 + 소리 포함) 안내 음성이 계속 들리는 것을 10초 이상 보여 준다.
5. 화면을 켜서 구간·문장 위치가 앞으로 진행된 것을 보여 준다.
6. **[일시정지] 또는 이어폰 버튼으로 멈춤** → [운동 마치기] → 알림이 사라지는 것을 보여 준다(서비스가 바로 끝남).

녹화 팁: 화면 녹화는 소리를 함께 담도록 설정하고, TalkBack을 켠 상태로 한 번 더 찍어 두면 접근성 목적 설명에 도움이 된다.

## 4. 점검 목록(출시 전)

- [ ] release 병합 매니페스트에 `foregroundServiceType="mediaPlayback"`와 `FOREGROUND_SERVICE_MEDIA_PLAYBACK`가 있다(`./gradlew :app:checkReleaseManifestPermissions` 출력에서 확인).
- [ ] 같은 검사에서 `READ_SMS`·`RECEIVE_SMS`·`READ_CALL_LOG`가 없다(P-10, CI 실패 조건).
- [ ] 알림 권한(POST_NOTIFICATIONS)을 거부해도 서비스·재생은 동작한다(알림만 숨겨짐) — 거부 시 안내 문구는 T-13 작업에서 추가.
- [ ] 개인정보처리방침·Data safety에는 이 서비스로 추가 수집하는 정보가 없음(재생만 함).
