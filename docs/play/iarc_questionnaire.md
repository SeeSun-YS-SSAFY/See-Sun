# 콘텐츠 등급(IARC) 설문 답안 — P-08

> 초안 v0.1. 근거: Play 콘텐츠 등급 도움말(answer/9898843).
> IARC 설문 문구와 순서는 바뀔 수 있습니다. 아래는 질문의 **주제별 답**입니다. 콘솔에서 질문을 하나씩 읽으며 이 표의 사실로 답합니다. `[확인 필요: 제출 시 콘솔 문구 대조]`
> 거짓으로 답하면 등급이 취소되거나 앱이 삭제될 수 있습니다. 애매하면 보수적으로(예) 답하고 설명을 남깁니다.

## 1. 기본 정보

| 항목 | 답 |
|---|---|
| 연락 이메일 | ○○○ (등급 증명서가 이 주소로 옴) |
| 앱 유형(카테고리) | 게임이 아님. 참고·건강·생산성 등 "기타 앱" 유형 `[확인 필요: 콘솔 선택지 이름]` |

## 2. 주제별 답 (2차 기준)

| 주제 | 답 | 근거 |
|---|---|---|
| 폭력(사실적·만화·유혈) | 아니요 | 운동 동작 그림만 있음 |
| 성적 내용, 노출 | 아니요 | 운동 그림은 단순 픽토그램 |
| 비속어·저속한 표현 | 아니요 | 안내 문구만 있음 |
| 공포·무서운 내용 | 아니요 | — |
| 약물·알코올·담배 묘사나 사용 권장 | 아니요 | 식품 영양 정보에 술 이름이 검색될 수 있으나 음주를 권하거나 묘사하지 않음 `[확인 필요: 음식 DB에 주류 행이 있는지]` |
| 도박, 모의 도박 | 아니요 | — |
| 사용자 간 소통(채팅·게시판) | 아니요 | 사용자끼리 연락하는 기능 없음 |
| 사용자 제작 콘텐츠 공유 | 아니요 | 기록은 본인만 봄 |
| 사용자 위치 공유 | 아니요 | 위치 수집 없음 |
| 개인정보 공유 | 아니요 | 다른 사용자나 제3자에게 공개하지 않음 |
| 디지털 상품 구매(앱 안 결제) | 아니요 | 무료, 결제 없음 |
| 제한 없는 인터넷 접속(웹 브라우저 기능) | 아니요 | 앱 안에서 임의 웹 탐색 기능 없음. 처리방침 링크는 외부 브라우저로 엶 |
| 광고 | 아니요 | — |

## 3. 3차(복약) 때 다시 볼 것

| 주제 | 판단 |
|---|---|
| 약물 관련 질문 | 처방약·일반약의 **복용 시간 알림**은 약물 남용 묘사나 권장이 아님. 설문이 "약물 언급"을 넓게 묻는다면 "의약품 이름이 표시됨(복약 알림)"으로 설명을 남기고 보수적으로 답함 `[확인 필요: 3차 제출 시]` |
| 의약품 제품명 검색 | 효능·용법을 보여 주지 않음(검토서 §4.2) |

3차 업데이트에서 콘텐츠가 바뀌면 설문을 다시 제출합니다.
