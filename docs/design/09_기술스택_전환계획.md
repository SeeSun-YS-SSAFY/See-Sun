### T1. 클라이언트 PoC 게이트 (1주) ⏳
- 목적: Kotlin + Compose 선택(08 §4.1)을 실제 기기에서 검증하고, 팀의 Kotlin 적응 기간을 겸합니다. 알람·접근성 등에서 막히는 항목이 있으면 원인과 대안을 기록합니다(iOS 동시 출시가 확정되면 RN 재검토).
- 범위(07 D-01의 5개 항목)와 통과 기준

| # | 항목 | 통과 기준 |
|---|---|---|
| 1 | 스크롤 강조 목록 + TalkBack | TalkBack으로 19개 항목을 [이전][다음]과 스와이프 탐색 모두 가능, 항목 변경 시 이름 낭독, 포커스 유실 없음 |
| 2 | 정확한 알람(Kotlin 모듈) | Doze 상태에서 ±1분 이내 울림, 재부팅 후 재등록, 전체화면 알림(허용 시)·대체 알림 동작, 알림 액션 2개 동작 |
| 3 | 음성 인식 | ko-KR 온디바이스 인식(지원 기기), 숫자·날짜 10개 문장 파싱 성공 8개 이상, TalkBack 켜짐 시 앱 TTS와 겹치지 않음 |
| 4 | 카메라 | 바코드 실시간 인식 → 진동 → 자동 촬영, 영양성분표 한글 OCR로 kcal·당류 추출 |
| 5 | 인증 | Firebase 전화번호 인증 자동 완료(SMS 권한 없이), 서버 토큰 교환 성공, **reCAPTCHA 대체 화면 발생 빈도 측정**(잦으면 NHN + SMS Retriever) |

- 테스트 기기: 삼성 One UI 1대 + 픽셀 1대 이상(06 문서 기기 매트릭스).
- 산출물: PoC 결과표(통과/실패, 영상), D-01 확정 기록.

## 3. 위험과 대응

| 위험 | 영향 | 대응 |
|---|---|---|
| 팀의 Kotlin 적응 지연 | 일정 | PoC 주간을 적응 기간으로, 공통 모듈을 먼저 만들어 화면은 패턴 복제, Compose는 React와 같은 선언형 모델 |
| 온디바이스 한국어 인식 미지원 기기 다수 | 국외이전 고지 필요, 인식률 | 일반 인식으로 대체 + 처리방침 고지, 유저테스트 인식률 측정 |
| 공공 API 품질·커버리지 부족(바코드 C005·I2570은 2018년 이후 갱신 중단) | 추천·경고 정확도, 바코드 조회 실패 | 포장 OCR 우선, 관리자 검수, 추천 목록 자체 선별, 오류 신고 기능 |
| 이 개발 환경에서 Android SDK 다운로드 불가 | 로컬 APK 빌드 불가 | **APK 빌드는 GitHub Actions에서 수행**, 로컬은 팀원 PC |
| 1차 웹 데모가 STT 인증 추가로 깨짐 | 데모 중단 | 2-3 결정 시 웹 데모 필요 여부 확인 |
