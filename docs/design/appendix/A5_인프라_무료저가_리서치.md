# enVision 인프라 선택지 조사 (기준일 2026-09-30)

대상: Django 5.2 + DRF + gunicorn(Docker), PostgreSQL, 공개 미디어 약 300MB(픽토그램, mp3), 한국 Android 클라이언트. 사업자등록 없이 회원 개인 카드로 결제.
환율: 1 USD ≈ 1,353 KRW (2026-09-30 종가, [아시아경제](https://view.asiae.co.kr/article/2026093015594666636)). 아래 표에서는 **1 USD = 1,350원**으로 계산함.

## 0. 검증 방법과 표기

- WebSearch는 쓸 수 있었음. **WebFetch는 거의 모든 공식 페이지에서 네트워크 정책으로 차단됨**(docs.oracle.com, render.com, supabase.com, neon.com, firebase.google.com, infoq.com). cloud.google.com 페이지 하나는 열렸지만 표가 잘려서 쓸 수 없었음.
- 그래서 **이 문서의 수치는 전부 검색 결과 요약([S])에 기댐.** 공식 페이지를 직접 열어 대조한 수치는 없음.
- **[미검증]**: 출처가 서로 다르거나, 출처를 못 찾았거나, 추정한 값.
- 지연시간(RTT)은 한국 기준 대략값: 서울·춘천 5~10ms, 오사카·도쿄 30~45ms, 싱가포르 70~90ms, 미국 서부 130ms 이상. 측정한 값이 아니라 **[미검증]**.

## 추천 (이 프로젝트 기준 순위)

### Demo / 사용자 테스트 단계 (지금~수개월)

1. **Lightsail 서울 $7(1GB) 또는 $12(2GB) 번들 3개월 무료 + Docker Compose(Caddy+gunicorn+PG) + R2** (조합 3)
   - 첫 3개월 $0, 이후 약 9,450~16,200원.
   - 앱과 DB가 모두 **서울**에 있어 국외 이전 고지 부담이 거의 없고(R2·CF는 미디어만 다룸), 콜드스타트도 없음.
   - AWS 새 무료 플랜의 6개월 계정 폐쇄 조항 때문에 **처음부터 유료 플랜으로 가입**할 것. Lightsail 3개월 무료가 크레딧 계정에서도 적용되는지는 확인 필요 [미검증].
   - 기존 docker-compose를 거의 그대로 쓸 수 있고, 나중에 managed DB로 옮기기도 쉬움.
2. **Azure for Students (Korea Central)**: 카드가 없을 때 가장 좋은 선택. 크레딧 $100 + PG B1ms 12개월 무료. 학생 자격이 끝나거나 크레딧이 소진되면 정지되는 점이 리스크.
3. **iwinv 1GB(약 6,160원) 또는 NCP Micro(공인 IP 4,032원)**: 국내·최저가. 1GB 메모리에서 PG(28만 행) + Django가 돌아가는지 부하 테스트가 필요하고, 스왑을 설정해야 함.
4. Oracle Always Free: **춘천 A1 무료 불가 + 서울 신규 가입 불가 보고** 때문에 한국 리전으로는 사실상 어려움. 도쿄·오사카 홈 리전 A1 2/12는 무료지만 계정 종료 리스크가 커서 **건강정보를 다루는 주 서버로는 비추천**. 쓰더라도 백업 서버나 스테이징 용도로만.
5. Render/Koyeb Free, Supabase Free 단독: 슬립·만료·7일 정지·백업 없음 때문에 **부적합**.

### Launch 단계 (약 1,000명)

1. **Lightsail 서울 $12 VM + Lightsail Managed PG $15 + R2** (약 $27, 약 36,500원/월, 조합 2 변형)
   - 건강정보 DB를 **관리형 자동 백업**으로 운영하고, 모두 서울 리전에 둠. 벤더가 하나라 결제 카드도 하나.
   - 트래픽이 늘면 $24 VM, $30 DB로 한 단계씩 올리면 됨(growth 약 $54).
2. **Lightsail 서울 $12~24 VM + 직접 운영 PG + 매일 pg_dump → R2(+ wal-g) + Healthchecks.io 감시** (약 $15~30)
   - 비용은 가장 적지만 복구 리허설을 문서화하고 담당자를 정해야 함.
3. **Cloud Run 서울(min-instance 1) + Supabase Pro 서울** (약 $40~50): OS 패치 부담이 없음. 과금 폭주 대비 예산 알림 필수.
4. **국내 VPS(iwinv/NCP) + 직접 운영 PG**: 원화 결제, 국내 지원. 관리형 DB가 필요하면 NCP Cloud DB 가격을 먼저 확인.
5. Fly 도쿄 + Supabase, Railway/Render 싱가포르: 개발 경험(DX)은 좋지만 한국과의 지연·국외 이전 고지·앱↔DB 왕복 지연 면에서 불리.

**SMS OTP:** 구조가 간단하려면 Firebase Phone Auth(Blaze, 한국 단가 확인 필요), 단가가 중요하면 **알리고(8.4원, 본인 명의 번호)**. NHN Cloud는 개인이 쓸 수 없음.

**공통 권장 구성:** Cloudflare DNS + R2(미디어) + Caddy 자동 TLS + Sentry Developer + Healthchecks.io(백업 cron) + UptimeRobot 또는 Better Stack(가동 감시) + GitHub Actions(2,000분).

## 결정 전 검증할 것

1. **Lightsail 서울 가격**: 콘솔에서 $7/$12 번들과 $15 DB의 서울 가격·포함 전송량을 확인하고, 새 AWS 가입 시 "유료 플랜"을 선택해도 Lightsail 3개월 무료가 적용되는지 확인.
2. **Oracle**(검토한다면): 가입 화면에서 서울 홈 리전을 고를 수 있는지, 춘천에서 A1 Always Free를 쓸 수 없다는 문서 문구를 직접 확인(WebFetch가 차단돼 검색 인용만 봄). PAYG 전환 비용(초기 선승인 등)도 확인.
3. **Firebase Phone Auth 한국(+82) SMS 단가**: Identity Platform 가격표에서 확인하고, 일 10건 무료가 아직 유효한지도 확인. 예산 알림을 설정하고 SMS 허용 지역을 한국으로 제한.
4. **알리고·솔라피**: 개인 가입, 본인 명의 번호 등록, 통신서비스 가입증명원 절차, 동아리 명의 사용 가능 여부.
5. **Supabase 서울 리전**: Free/Pro 생성 화면에서 서울이 선택되는지, PITR 추가 요금, Pro에 포함된 DB 8GB와 egress 250GB 수치 [미검증].
6. **메모리 부하 테스트**: 1GB VM에서 PG(음식 DB 28만 행) + gunicorn 2 worker가 OOM 없이 도는지 확인. 스왑 1~2GB 설정.
7. **R2**: 커스텀 도메인 연결, mp3 Range 요청이 캐시되는지, Cache Rule 설정 확인.
8. **개인정보 처리방침**: 해외 리전(도쿄·싱가포르·Cloudflare 등)을 쓰면 제28조의8에 따라 이전받는 자, 국가, 항목, 시기·방법, 보유기간을 고지해야 함. 클라우드 보관은 "처리위탁"으로 봄. Sentry·Firebase·Cloudflare도 수탁자로 기재.
