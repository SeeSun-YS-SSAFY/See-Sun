# See:Sun 인프라 외 기술 대안 조사 (기준일 2026-09-30)

**범위:** 호스팅, DB 호스팅, 스토리지, CDN, 도메인은 제외했다(다른 에이전트 담당).
**표기:**
- **[공식]** 공식 가격 페이지나 패키지 레지스트리(PyPI/npm/Maven Central)를 직접 받아서 확인한 사실
- **[S]** 검색 결과 요약으로만 확인한 사실. 원문 페이지는 직접 열어 보지 않았다.
- **[미검증]** 기존 지식이나 추론이다. 도입 전에 공식 문서로 다시 확인해야 한다.

**적합도:** 이 프로젝트 조건 기준이다(TalkBack 우선, 학생 동아리, 사업자 없음, 개인카드, 비용 최소화). 상/중/하로 표시한다.

## 0. 먼저 알아야 할 결론 (TL;DR)

1. **Firebase 전화 인증은 한국 SMS가 건당 $0.01로 싸다 [공식].** 다만 **Spark(무료) 플랜에서는 SMS를 보낼 수 없다.** 2024-09부터 Blaze(결제 계정 연결)가 필수다 [S].
   - 개인카드를 등록해야 하므로 **SMS 지역 허용목록을 KR로만 제한하고 예산 알림을 설정해야 한다 [공식: SMS regions 기능 안내].**
   - Play 스토어 밖에서 설치한 빌드(Firebase App Distribution 등)는 Play Integrity가 실패한다. 이때 **reCAPTCHA 웹 화면으로 폴백**된다 [S]. 시각장애 테스터에게는 접근성 장벽이 될 수 있다.
   - 대응: 테스트는 Play 내부 테스트 트랙으로 배포하거나, 테스트용 전화번호를 사용한다.
2. **국내 SMS 게이트웨이 가운데 개인이 가입할 수 있는 곳은 솔라피(=쿨SMS 계열, 18원/건 VAT 별도)와 알리고(8.4원/건, 최소 충전 5만 원, 개인 1일 500통 제한)뿐이다 [S].**
   - NHN Cloud는 2023-12-15부터 개인 회원이 이용할 수 없다 [S].
   - 네이버 SENS SMS는 2024-04-11부터 개인 회원 대상 서비스를 중단했다 [S].
3. **PASS 본인인증은 사업자등록이 필요하고 건당 300~500원이다 [S]. 제외를 권장한다.**
4. **STT와 TTS는 온디바이스(무료) 조합이 최선이다.**
   - ML Kit GenAI Speech Recognition이 2026-01 알파로 출시됐고 ko-KR을 지원한다(Basic은 beta) [S]. 대체 후보로 검토할 가치가 있다.
   - 운동 안내 mp3를 사전 생성하는 용도라면 **Google Cloud TTS Standard/WaveNet 월 400만 자 무료 [공식]** 또는 **Azure F0 월 50만 자(초과 시 과금 대신 차단) [S]** 로 비용 0원이 가능하다.
5. **Gemini API는 18세 미만이 쓸 가능성이 있는 서비스에 사용할 수 없다(유료/무료 공통) [S]. 무료 티어 데이터는 학습에 쓰인다 [S].**
   - 건강 앱에서 클라우드 LLM이 필요하다면 OpenAI API(기본적으로 학습 미사용 [S])나 Upstage Solar(저가, 한국어)가 낫다.
   - 다만 현재 요구사항은 규칙 기반 파서로 충분하다.
6. **Realm은 Device Sync가 2025-09-30에 종료됐다(EOL) [S].** 로컬 DB는 Room+SQLCipher를 유지하면 된다.
7. **학생 혜택이 매우 크다.** GitHub Student Pack에는 Sentry 학생 플랜(에러 5만 건/월, 1년) [S], 1Password 2년 무료 [S], Appwrite Education(Pro 상당) [S], JetBrains 무료 [S]가 있다. Figma Education(Professional 무료) [S], Notion Education Plus 무료 [S]도 받을 수 있다.
8. **OneSignal 무료 플랜은 2026-09-01(신규)과 2026-10-01(기존)부터 모바일 푸시에 MAU 1,000 제한이 생긴다 [S].** 서버 푸시가 필요하면 FCM(무료)을 쓴다.

**SMS Retriever 호환성:**
- 국내 웹발송 문자는 `[Web발신]` 접두어가 붙는다. 그래도 Retriever가 동작한다는 국내 개발자 사례가 있다 [S].
- 메시지는 140바이트 이내여야 하고 11자 앱 해시로 끝나야 한다 [S].
- 한국 단문(SMS)은 90바이트다. 한글을 줄이고 "인증번호 123456" 정도에 해시를 붙이는 식으로 짧게 구성해야 한다 [미검증].
- 해시가 필요 없는 **SMS User Consent API**가 더 안전한 선택이다. 한 번 탭하는 시스템 다이얼로그라 TalkBack으로 읽힌다 [미검증].

**추천:** **솔라피**(가입 문턱이 낮고 소량 발송에 적합)를 쓴다. 대량 발송이 예상되면 **알리고**로 옮긴다.

## 주요 비용 리스크

1. **Firebase 전화 인증 SMS 과금과 SMS 펌핑.**
   - Blaze와 개인카드가 필수다. KR은 $0.01/건으로 싸지만 봇이 해외 번호로 대량 요청하면 지역별 최대 $0.46/건까지 나온다 [S/공식].
   - 대응: SMS 지역 허용목록 KR, App Check, 예산 알림(알림일 뿐 상한은 아님 [미검증]), 계정당·기기당 레이트리밋.
2. **유료 TTS 생성 비용.**
   - Chirp 3 HD($30/100만 자)나 Studio($160/100만 자) [공식] 같은 고급 음성으로 재생성을 반복하면 비용이 급증한다.
   - 대응: Standard/WaveNet 무료 400만 자 안에서 처리하고, 결과물을 캐시·버전 관리해서 재생성을 막는다.
3. **Google Cloud 결제 계정의 자동 과금 구조(TTS/Vision/STT).** Azure F0처럼 초과 시 차단되는 서비스와 달리 한도를 넘으면 자동으로 과금된다 [공식/S]. API 쿼터 상한을 직접 설정해야 한다.
4. **SMS 게이트웨이 선충전 및 정책 변경.**
   - 알리고는 최소 5만 원 선충전이 있다 [S].
   - 국내 사업자들이 잇따라 개인 회원 이용을 막았다(NHN 2023-12, SENS 2024-04) [S]. 솔라피도 정책이 바뀔 수 있다.
5. **클라우드 LLM 도입 시 약관과 비용.** Gemini API는 18세 미만 서비스 금지 조항이 있고 무료 티어 데이터가 학습에 쓰인다 [S]. 다른 API는 토큰 비용이 누적된다.
6. **무료 티어 축소 추세.** OneSignal(MAU 1,000), Appwrite(Free 플랜을 여러 차례 축소 [S]), Clerk와 Auth0 개편 등. 벤더 락인을 최소화해야 한다.
7. **Play 비공개 테스트 12명×14일 요건.** 직접 비용은 없지만 출시 일정이 지연될 위험이 있다 [S].
8. **Maestro Cloud / BrowserStack 등 유료 기기 클라우드.** Maestro Cloud는 기기당 $250/월이다 [S]. 로컬과 실기기 위주로 테스트한다.
