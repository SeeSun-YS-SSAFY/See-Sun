## 3. 1차 구조 (as-is)

```
[브라우저(Next.js 16, React 19, jotai)]
   │  REST (JWT, localStorage 저장)          │ 마이크 → WebM/Opus 업로드, WebSocket
   ▼                                         ▼
[Django 5.2 + DRF + Channels(daphne)] ──► Google Cloud STT (ko-KR)
   │  ├─ users (Clean Architecture: containers/services/repositories/infrastructure, Google OAuth)
   │  ├─ exercises (카테고리·운동·미디어·플레이리스트, Celery로 오디오 병합)
   │  ├─ logs (세션·세션항목·이벤트·로그객체)
   │  └─ stt (HTTP/WS, 웨이크워드, Gemini 정규화·명령 해석) ──► Gemini 2.0 Flash (AI Studio 키)
   ├─ PostgreSQL 15, Redis(Celery 브로커)
   └─ /media (로컬 파일: 음성 mp3, git 미추적) · /static (픽토그램 112장, git 추적)
관리 명령: update_media(gTTS), generate_nav_audio(Gemini+Cloud TTS), update_pictograms, populate_name_en(Gemini)
```

- **운영 배포 흔적 없음.** docker-compose는 로컬 개발용(runserver, `npm run dev`). AWS(S3/ECS/EC2)는 문서에 계획만 있고 코드 없음. Notion에 AWS 계정 항목 존재 → 계정 내 리소스 확인 필요.
- **S3 연결 지점:** `ExerciseMedia.s3_key`(실제로는 음성 구간 라벨로 오용), `ExerciseLogObject.s3_key`(업로드 코드 없음), 문서상 버킷 `seesun-media`(ap-northeast-2). 프론트는 모든 미디어를 `NEXT_PUBLIC_API_MEDIA_URL + 상대경로`로 불러오므로 배포 env로 CDN을 가리켰을 가능성은 있음. 단 병합 오디오·안내 음성·일부 하드코딩 때문에 env만으로 S3 전환은 불가.
- **영상:** 1차 코드·데이터에 영상 없음. 0차 앱 자산일 가능성.
