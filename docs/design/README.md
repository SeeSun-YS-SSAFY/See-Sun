## 핵심 결론 (한 페이지 요약)

1. **1차는 "웹앱 프로토타입" 단계입니다.** Next.js 16 + Django + Google STT/TTS + Gemini. 운동(단일·루틴·커스텀) 흐름은 동작하지만 **빌드 실패, 15분마다 강제 로그아웃, 안내 음성 무음, TalkBack 사용 불가 화면**이 있어 그대로 APK로 배포할 수 없습니다.
2. **2·3차는 Android 앱을 전제**로 합니다(TalkBack, 기기 STT/TTS, ML Kit, 정확한 알람, SMS 자동입력). 1차 Next.js 화면 코드는 그대로 쓰기 어렵고, **백엔드·콘텐츠(운동 29종, 픽토그램, 음성)·디자인 토큰은 재사용**합니다. → 최종 스택(08 문서): **Kotlin + Jetpack Compose 네이티브 + Django 5.2 LTS 백엔드 보강 + AWS Lightsail(서울)**.
3. **법적으로 설계를 바꿔야 하는 곳이 있습니다.** "당뇨 위험도" 명칭·등급(의료기기 경계), 건강정보 **별도 동의**, 만 14세 미만 차단, Gemini(18세 미만 금지 약관·무료 티어 학습 이용), 처리방침·약관 신규 작성, IRB 확인.
4. **데이터·콘텐츠 중 비어 있는 것:** 2차 의뢰서 첨부 3종(식단스코어 설계, 알레르기 대체 식단, 당뇨 기준 원문), 추천 음식 엑셀, 0차 영상/S3 자산 → 요청 발송, 미수령 시 자체 조사(02 문서 §5).
5. **보안 즉시 조치:** 평문 보관 자격증명 교체, STT API 인증 추가, SECRET_KEY 교체.
