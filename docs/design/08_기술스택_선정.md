## 0. 선정 원칙과 공통 평가 기준

| REUSE | 1차 재사용 | 1차 백엔드·콘텐츠·토큰 |

원칙
1. 음성·사진은 기기 안에서 처리, 서버에는 확인된 구조화 데이터만.
2. Android 공식 API·Jetpack 우선. 핵심 기능을 개인 유지보수 라이브러리에 걸지 않음.
3. **개인정보를 다루는 서버·DB는 국내(서울) 리전**, 개인정보가 없는 공개 미디어만 글로벌 CDN.
4. 무료 한도로 시작하되 **슬립·만료·자동 정지·백업 없음** 같은 무료 티어 제약이 복약·기록 동기화를 깨면 제외.
5. 과금형 서비스에는 예산 경보 + 사용량 상한(쿼터)을 함께 건다.

**판단 기준(3개월 뒤·출시 시점에 결정)**
- 건강정보 DB의 **백업·복구를 동아리가 직접 책임질 여력이 없다** → Lightsail + 관리형 DB.
- 월 1~2만 원 절감이 중요하고, **매일 pg_dump → R2 백업 + Healthchecks.io 감시 + 분기 1회 복구 리허설**을 담당자가 맡을 수 있다 → 국내 VPS(iwinv 등) + 직접 DB. 원화 결제·한국어 지원도 장점.
- 해외 결제가 어렵다 → 국내 VPS 또는 Azure for Students.
- **비용이 최우선이고 한국 밖 서버(지연 약 80~150ms, 국외이전 고지)를 감수**할 수 있다 → Hostinger(4GB가 월 약 8,760원). 앱은 오프라인 우선·백그라운드 동기화라 지연 영향은 작지만, 2년 선결제와 갱신가 인상, 동아리 인수인계(결제 계정 소유자) 조건을 먼저 확인합니다.
- 어느 쪽이든 1GB 서버는 **Postgres(음식 DB 28만 행) + gunicorn 2개가 메모리 안에 들어가는지 부하 테스트**와 스왑 설정이 선행 조건입니다.
