## 0. 선정 원칙과 공통 평가 기준

| 코드 | 기준 | 설명 |

| A11Y | 접근성 | TalkBack만으로 전 기능 사용(검수 ②), 제스처 전용 금지 |

| MAINT | 유지보수·의존성·벤더 위험 | 팀원 교체, 라이브러리 중단, **무료 티어 폐지·계정 정지 이력** |
| REUSE | 1차 재사용 | 1차 백엔드·콘텐츠·토큰 |

원칙
1. 음성·사진은 기기 안에서 처리, 서버에는 확인된 구조화 데이터만.
2. Android 공식 API·Jetpack 우선. 핵심 기능을 개인 유지보수 라이브러리에 걸지 않음.
3. **개인정보를 다루는 서버·DB는 국내(서울) 리전**, 개인정보가 없는 공개 미디어만 글로벌 CDN.
4. 무료 한도로 시작하되 **슬립·만료·자동 정지·백업 없음** 같은 무료 티어 제약이 복약·기록 동기화를 깨면 제외.
5. 과금형 서비스에는 예산 경보 + 사용량 상한(쿼터)을 함께 건다.
