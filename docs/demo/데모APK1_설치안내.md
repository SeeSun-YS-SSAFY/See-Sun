# 데모 APK #1 설치·시험 안내 (운동 기능)

> 대상: 이준영 CTO(소유자) · 작성 2026-10-12 · 브랜치 `feat/w2-exercise`
> 이 APK는 **개발용 debug 빌드**입니다. 가짜 인증(인증번호 `123456`, 문자 없이 자동 입력)과 PC의 로컬 백엔드를 씁니다. 실제 사용자에게 배포하지 마세요.
> 2026-10-13 개정: 온보딩·마이페이지가 합쳐져 **데모 계정 버튼은 없어졌고 온보딩으로 가입**합니다(4번).

준비물: Windows PC(이 저장소, `backend\.venv` 설치됨), Android 휴대폰(Android 8.0 이상), 데이터 전송이 되는 USB 케이블.
`adb`는 Android SDK의 `platform-tools` 폴더에 있습니다(`C:\Users\<사용자>\AppData\Local\Android\Sdk\platform-tools\adb.exe`). 아래 명령의 `adb`는 이 파일을 뜻합니다.

---

## 1. 휴대폰에서 개발자 옵션과 USB 디버깅 켜기

1. **설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호**를 7번 연속 누릅니다. "개발자 모드를 켰습니다"가 나오면 됩니다. (삼성 외 기기는 **설정 → 휴대전화 정보 → 빌드 번호**)
2. **설정 → 개발자 옵션 → USB 디버깅**을 켭니다.
3. USB로 PC에 연결하고, 휴대폰에 뜨는 **"USB 디버깅을 허용하시겠습니까?"**에서 "이 컴퓨터에서 항상 허용"을 체크하고 **허용**을 누릅니다.
4. PC에서 확인합니다. 기기가 `device`로 보이면 됩니다(`unauthorized`면 3번을 다시).
   ```powershell
   adb devices
   ```

## 2. PC에서 백엔드 켜기

저장소 맨 위 폴더에서 PowerShell로 실행합니다. 처음 한 번은 1~2분 걸립니다.

```powershell
powershell -ExecutionPolicy Bypass -File scripts\demo\run_local_backend.ps1
```

이 스크립트가 하는 일:
- 안내 음성 mp3 234개가 없으면 옛 브랜치에서 복구(`ops/media/restore_from_git.sh`, git에 올리지 않음)
- DB 준비(Docker 없이 `backend\db.sqlite3`), 마이그레이션
- 운동 29종·픽토그램·안내 음성 연결, 음식 샘플, 동의 문서 적재
- 개발 전용 가짜 Firebase 검증기 켜기, `http://0.0.0.0:8000`에서 서버 실행

"서버 실행"이 나오면 창을 그대로 두세요(끄려면 Ctrl+C). DB를 처음 상태로 돌리려면 `-Reset`을 붙입니다.

점검(선택): 다른 PowerShell 창에서
```powershell
backend\.venv\Scripts\python.exe scripts\demo\smoke_api.py
```
"모두 통과"가 나오면 로그인·운동 목록 29개·안내 음성/그림 주소(200)·기록 저장이 정상입니다.

## 3. APK 설치와 연결(adb install → adb reverse)

1. APK 만들기(이미 받은 APK가 있으면 건너뜀). `android` 폴더에서:
   ```powershell
   .\gradlew.bat :app:assembleDebug
   ```
   결과: `android\app\build\outputs\apk\debug\app-debug.apk`
2. 설치:
   ```powershell
   adb install -r android\app\build\outputs\apk\debug\app-debug.apk
   ```
   휴대폰에 "시선" 앱(패키지 `kr.seesun.app.debug`)이 생깁니다.
3. 휴대폰이 PC 백엔드에 닿게 하기(**USB를 다시 꽂거나 휴대폰을 재시작하면 다시 실행**):
   ```powershell
   adb reverse tcp:8000 tcp:8000
   ```
   휴대폰의 `127.0.0.1:8000`이 USB를 통해 PC의 8000번으로 갑니다. 와이파이·같은 네트워크가 필요 없습니다.
4. 앱 실행 → **[처음 시작하기]** → 생년월일 → 안내·동의 → 전화번호(아무 휴대폰 번호, 예: 010-5555-0001) → [인증번호 받기]를 누르면 인증번호가 저절로 들어갑니다(직접 넣을 때는 `123456`) → 이름·성별·키·몸무게 → 건강 정보 → "가입 완료". 그다음 메인에서 [운동]으로 갑니다. 같은 번호로 다시 쓰려면 [이미 가입했어요].
   (서버에 닿지 못하면 휴대폰에 내장된 운동 정보·대본을 기기 음성으로 읽고, 기록은 연결되면 서버로 보냅니다.)

## 4. 시험 목록 — TalkBack을 켜고, 화면을 끄거나 보지 않고

TalkBack 켜기: **설정 → 접근성 → TalkBack → 사용**(볼륨 키 두 개를 3초 누르는 바로가기를 켜 두면 편합니다). TalkBack에서는 **한 번 눌러 고르고, 두 번 눌러 실행**합니다. 오른쪽으로 쓸면 다음 항목입니다.

| # | 해 볼 것 | 확인할 것 |
|---|---|---|
| 1 | [운동] 화면 진입 | 화면 이름 "운동"을 먼저 읽는다. 안내 음성이 저절로 나오지 않는다 |
| 2 | [한 가지 운동] → [근력 운동] | 목록에서 [다음]/[이전] 버튼만으로 8개를 모두 갈 수 있다. "2번째, 전체 8개. 플랭크"처럼 읽는다. 스와이프 없이도 된다 |
| 3 | 처음 운동을 고를 때 | "운동 안전 안내"가 먼저 나온다(공간 안전·멈추는 방법). 건강 확인 7문항에 예/아니요. 답은 휴대폰에만 저장된다 |
| 4 | 재생 화면 진입(TalkBack 켜짐) | **자동 재생하지 않는다**. "상태: 준비됨". [재생]을 두 번 눌러야 시작 |
| 5 | [재생] 후 **화면을 끄고** 1~2분 | 안내 음성이 계속 나온다. 다시 켜면 "구간 3/5"처럼 앞으로 가 있고 지금 문장이 "▶"로 표시돼 있다 |
| 6 | 운동 중 **이어폰 버튼** 한 번 | 즉시 멈춘다("상태: 일시정지"). 한 번 더 누르면 이어서 |
| 7 | 운동 중 전화 받기(다른 휴대폰으로 걸기) | 안내가 멈추고, 통화가 끝나면 이어서 나온다 |
| 8 | 운동 중 **뒤로 가기** | "운동을 끝낼까요?" 대화상자. [계속하기]면 그대로, [기록하고 끝내기]면 저장 |
| 9 | [운동 마치기] | "맨몸 스쿼트 운동을 기록했어요. ○분 ○초…" + 짧은 진동 |
| 10 | [루틴 운동] → [근력 운동 루틴] → [루틴 시작] | 운동이 끝나면 "휴식 10초. 다음 운동: 플랭크" + 진동, 3·2·1초에 짧은 진동, 다음 운동이 저절로 시작. 화면을 꺼도 이어짐 |
| 11 | [나만의 루틴] → [새 루틴 만들기] | 이름 입력, [운동 넣기] → 운동 고르기 → 세트·횟수 [늘리기]/[줄이기] → [루틴 저장]. 제스처 없이 버튼만으로 된다 |
| 12 | **비행기 모드**로 운동 시작·끝내기 | 이미 받은 안내 음성은 계속 나온다. 끝내면 "보내지 못한 운동 기록 1건". 비행기 모드를 끄면 잠시 뒤 자동으로 보내지고 문구가 사라진다(adb reverse가 끊겼으면 3-3을 다시) |
| 13 | [이번 주 운동 기록] | "이번 주 운동 ○회, 총 ○분이에요."와 요일별 목록을 읽는다 |
| 14 | 글꼴 크기 최대(설정 → 디스플레이 → 글꼴 크기) | 글자가 잘리지 않고, 화면을 내리면 모든 버튼에 닿는다 |
| 15 | 버튼을 빠르게 두 번 | 같은 화면이 두 번 열리지 않는다. 재생이 켜졌다 바로 꺼지지 않는다 |

결과는 06 문서 기기 매트릭스(기기 모델·Android 버전·TalkBack 버전)와 함께 적어 주세요.

## 5. 자주 막히는 것

| 증상 | 해결 |
|---|---|
| 목록 위에 "기기에 저장된 운동 정보예요" | 서버에 못 닿음: 백엔드 창이 켜져 있는지, `adb reverse tcp:8000 tcp:8000`을 했는지, 로그인했는지 |
| "로그인하지 못했어요" | 백엔드를 이 스크립트로 켰는지(가짜 검증기는 DEBUG에서만 켜짐) |
| `adb devices`에 안 보임 | 케이블(충전 전용 케이블은 안 됨), USB 디버깅 허용 팝업, 다른 USB 포트 |
| 안내 음성 대신 기계 음성 | 음성 파일을 못 받음: 백엔드 창에 `/media/…` 404가 있는지 확인, 스크립트를 `-Reset`으로 다시 |
| 설치 오류 `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | `adb uninstall kr.seesun.app.debug` 후 다시 설치 |

끝내기: 백엔드 창에서 Ctrl+C, `adb reverse --remove-all`.
