## 처음에 알려 드리는 요약

- 시선은 시각장애인과 저시력인을 위한 무료 생활 건강관리 앱입니다. 운동 안내와 식사 기록을 돕습니다.
- 운영자는 연세대학교 학생 동아리 enVision이며, 대표는 ○○○입니다.
- 가입할 때 전화번호와 생년월일을 받습니다. 이름(별명 가능), 성별, 키, 몸무게, 목표는 원하실 때 넣고, 맞춤 계산에 씁니다.
- 질환과 알레르기 정보는 따로 동의한 분에게만 받습니다. 동의하지 않아도 앱을 쓸 수 있습니다.
- 전화번호 인증을 위해 전화번호가 미국의 Google LLC(Firebase)로 전송됩니다.
- 음성과 사진은 휴대폰 안에서만 처리하고 서버로 보내지 않습니다.
- 개인정보를 다른 회사에 팔거나 제공하지 않습니다. 광고를 보내지 않습니다.
- 탈퇴하면 개인정보를 바로 지웁니다. 백업과 Firebase에는 정해진 기간 동안 남을 수 있습니다.
- 문의: 개인정보 보호책임자 ○○○, 전화 ○○○, 문자 ○○○, 이메일 ○○○

## 1. 개인정보를 처리하는 목적

enVision(이하 "운영자")은 다음 목적으로만 개인정보를 처리합니다. 목적이 바뀌면 미리 알리고, 필요하면 다시 동의를 받습니다.

| 목적 | 내용 |
|---|---|
| 회원 가입과 관리 | 전화번호로 본인 확인, 만 14세 이상 확인, 로그인 유지, 탈퇴 처리 |
| 운동 안내 | 운동 루틴 제공, 운동 기록 저장, 주간 운동 요약 |
| 식사 기록과 참고 점수 | 식사 기록 저장, 영양 성분 계산, 식단 참고 점수, 목표 칼로리 추정 |
| 맞춤 알림과 추천 | 알레르기 성분 알림, 당류·나트륨 정보 안내, 음식 추천(건강정보에 동의한 분만) |
| 복약 알림(3차, 출시 예정) | 정한 시간 알림, 복용 기록 `[확인 필요: 3차 출시 때 이 행을 확정하고 동의서 v2와 함께 개정]` |
| 문의와 권리 행사 대응 | 문의 답변, 열람·정정·삭제 요청 처리, 분쟁 대응 |
| 서비스 안정성 | 오류 확인, 부정 이용 방지, 보안 사고 대응 |

운영자는 개인 단위 기록을 분석하지 않습니다. 서비스 개선에는 개인을 알아볼 수 없는 집계 통계(예: 주간 가입자 수)만 씁니다.

## 2. 처리하는 개인정보 항목과 법적 근거

운영자는 **동의 없이 처리하는 항목**과 **동의를 받아 처리하는 항목**을 나누어 알립니다(개인정보 보호법 제22조 제3항).

### 2.1 서비스 제공(계약 이행)을 위해 처리하는 항목 — 동의 없이 처리

근거: 개인정보 보호법 제15조 제1항 제4호(정보주체와 맺은 계약의 이행)

| 구분 | 항목 | 필수·선택 | 쓰는 곳 |
|---|---|---|---|
| 가입 | 전화번호, 생년월일 | 필수 | 본인 확인, 만 14세 이상 확인, 계정 찾기 |
| 가입 | 이름(별명 가능) | 선택 | 앱 안에서 부르는 이름 |
| 프로필 | 성별, 키, 몸무게, 목표(체중 감량·근육 증진·건강 유지) | 선택. 입력하지 않으면 목표 칼로리를 계산하지 않음 | 목표 칼로리 추정, 운동 추천 순서 |
| 앱 설정 | 음성 안내 켜기, 음성 속도, 물리 버튼 음성 | 선택 | 화면 낭독 방식 |
| 식사 기록 | 날짜, 끼니, 음식 이름, 먹은 양, 영양 성분 값, 당류·탄수화물 지표, 포장 표시에서 읽은 알레르기 성분 | 이용 시 | 기록, 영양 계산, 참고 점수 |
| 운동 기록 | 운동 이름, 루틴, 시작·끝 시각, 완료 여부 | 이용 시 | 기록, 주간 요약 |

| 자동 생성 | 계정 식별번호(UUID), Firebase 식별번호(UID), 가입일, 마지막 접속일, 앱 로그인 토큰 | 필수 | 로그인 유지, 보안 |

`[확인 필요: C-03 결정 — 운영자가 위 기본 항목을 "동의"로 계속 받기로 하면, 이 절의 제목과 근거를 "제15조 제1항 제1호(동의)"로 바꾸고, 동의 화면 문구와 맞춥니다. 어느 쪽이든 민감정보(3절)와는 따로 적습니다.]`

### 2.2 동의를 받아 처리하는 항목

| 항목 | 근거 | 동의하지 않으면 |
|---|---|---|
| 질환(당뇨, 고혈압), 알레르기(19종 중 선택, 기타 직접 입력) | 개인정보 보호법 제23조 제1항 제1호(별도 동의) | 일반 모드로 씁니다. 운동, 식사 기록, 영양 정보, 참고 점수는 그대로 쓸 수 있습니다. 질환·알레르기 맞춤 알림과 추천만 빠집니다 |
| 광고성 정보 수신 | 정보통신망법 제50조 | 지금은 광고를 보내지 않으며, 동의를 받지 않습니다 |

### 2.3 수집 방법

- 앱 화면에서 직접 입력하거나 음성으로 말한 내용을 앱이 글자로 바꾸어 입력합니다.
- 인증 과정의 정보는 Firebase가 전화번호 인증 중에 자동으로 받습니다.
- 문의는 전화, 문자, 이메일로 받습니다.

## 3. 민감정보(건강정보) 처리

- 질환과 알레르기는 건강에 관한 정보라서 **민감정보**입니다. 다른 동의와 다른 화면에서 따로 동의를 받습니다.
- 질환을 반영한 식단 점수도 질환을 드러낼 수 있어 민감정보처럼 다룹니다.
- 서버에 저장할 때 암호화합니다.
- 설정에서 언제든 동의를 철회할 수 있습니다. 철회하면 질환·알레르기 정보와 질환을 반영한 점수를 **바로 지웁니다**.
- 장애 여부, 장애 정도, TalkBack 사용 여부는 **받지 않습니다**. TalkBack이 켜져 있는지는 휴대폰 안에서만 확인하고 서버로 보내지 않습니다.

**민감정보가 드러날 수 있는 상황과 막는 방법**(개인정보 보호법 제23조 제3항)

| 상황 | 막는 방법 |
|---|---|
| 앱이 알레르기·당류 정보를 소리 내어 읽을 때 주변 사람이 들을 수 있습니다 | 설정에서 음성 안내를 끄거나 음성 속도를 바꿀 수 있습니다. 이어폰을 쓰시기를 권합니다 |
| 3차 복약 알림이 잠금화면에 보일 수 있습니다 | 기본값은 약 이름 대신 "약 드실 시간이에요"만 보여 줍니다. `[확인 필요: 3차 출시 때 확정]` |

## 5. 파기 절차와 방법

**절차**

1. 탈퇴하거나 보유 기간이 끝나면 지체 없이 파기합니다.
2. 탈퇴 시 서버에서 바로 지우는 것: 이름, 전화번호, 생년월일, 성별, 키, 몸무게, 목표, 앱 설정, 건강정보, 식사 기록, 식단 점수, 즐겨찾기, 운동 기록, 루틴, 로그인 토큰.
3. 탈퇴 시 계정 행에는 가입일, 마지막 접속일, 탈퇴일만 남깁니다. 이 값으로는 누구인지 알 수 없습니다. 4절의 기간이 지나면 이 행도 지웁니다.
4. Firebase에 있는 인증 계정도 탈퇴 때 삭제를 요청합니다. 삭제 요청이 실패하면 다시 시도하고 그 기록을 남깁니다. Google은 삭제 요청 뒤 최대 180일 안에 시스템에서 지웁니다.
5. 백업 파일은 4절의 기간이 지나면 자동으로 지워집니다. 그 전에 백업을 되살리는 경우에는 탈퇴한 분의 정보를 다시 지운 뒤 씁니다.

**방법**

- 전자 파일과 데이터베이스 값은 복구할 수 없게 지웁니다.
- 종이 문서는 분쇄하거나 태웁니다. 지금은 종이 문서를 만들지 않습니다.

## 6. 제3자 제공

운영자는 개인정보를 제3자에게 제공하지 않습니다. 법률에 특별한 규정이 있거나 수사기관이 법에 따른 절차로 요구하는 경우에만 예외로 합니다.

## 7. 처리 위탁

운영자는 서비스를 위해 다음 업무를 맡깁니다(개인정보 보호법 제26조). 위탁 계약에 목적 외 처리 금지, 안전성 확보조치, 재위탁 제한, 관리·감독, 손해배상 책임을 넣고, 수탁자가 개인정보를 안전하게 처리하는지 점검합니다.

| 수탁자 | 맡기는 업무 | 국외 여부 |
|---|---|---|
| 이준영(개인 개발자) | 앱·서버 개발, 서버 운영 지원, 장애 대응 | 국내 |
| Amazon Web Services(AWS) | 서버와 데이터베이스 호스팅(서울 리전) | 국내 저장 |
| Google LLC(Firebase Authentication) | 전화번호 인증 문자 발송과 인증 | 국외(8절) |
| Cloudflare, Inc. | 공개 콘텐츠(운동 그림·음성) 배포, 도메인 연결 `[확인 필요: D-10 — 백업을 R2에 두면 "백업 보관" 추가]` | 국외(8절) |
| 오류 추적 서비스 | 지금은 쓰지 않습니다. 쓰게 되면 이 표와 8절을 고친 뒤 씁니다 | — |

수탁자나 맡기는 업무가 바뀌면 이 처리방침으로 알립니다.

## 9. 만 14세 미만 아동

- 시선은 만 14세 이상만 가입할 수 있습니다.
- 가입할 때 생년월일을 먼저 확인합니다. 만 14세 미만이면 가입을 막고, 입력한 생년월일도 저장하지 않습니다.
- 만 14세 미만 아동의 개인정보는 처리하지 않습니다. 실수로 처리된 사실을 알게 되면 바로 지웁니다.

## 10. 정보주체의 권리와 행사 방법

이용자는 언제든 다음 권리를 쓸 수 있습니다(개인정보 보호법 제35조~제38조).

| 권리 | 앱 안에서 | 앱 밖에서 |
|---|---|---|
| 내 정보 보기(열람) | 마이페이지에서 듣거나 보기 | 전화·문자·이메일로 요청 |
| 고치기(정정) | 마이페이지에서 수정 | 같음 |
| 지우기(삭제)와 탈퇴 | 설정 > 계정 > 회원 탈퇴 `[확인 필요: 앱 화면 경로 확정]` | 계정 삭제 요청 페이지 `[확인 필요: 게시 주소]`, 전화·문자·이메일 |
| 처리 정지, 동의 철회 | 설정에서 건강정보 동의 철회 | 전화·문자·이메일 |

- 모든 경로는 음성과 버튼으로 쓸 수 있게 만듭니다. 권리를 쓰는 방법이 가입할 때보다 어렵지 않게 합니다.
- 앱 밖에서 요청하면 본인 확인을 위해 가입한 전화번호를 여쭙니다. `[확인 필요: 본인 확인 방법 — 예: 가입 번호로 보낸 문자에 회신]`
- 요청을 받은 날부터 10일 안에 처리하고 결과를 알려 드립니다. 늦어지면 그 이유와 예정일을 알려 드립니다. `[변호사 확인: 처리 기한]`
- 대리인(법정대리인, 위임받은 사람)도 요청할 수 있습니다. 이때는 위임장을 받습니다.
- 법률에 따라 요청을 거절하거나 일부만 처리할 때는 그 이유와 이의 제기 방법을 알려 드립니다.

## 12. 휴대폰 안에서만 처리하는 정보와 앱 접근권한

**휴대폰 안에서만 처리하는 정보(서버로 보내지 않음)**

| 정보 | 처리 방법 |
|---|---|
| 음성 | 휴대폰의 음성 인식 기능으로 글자로 바꿉니다. 녹음 파일을 저장하거나 서버로 보내지 않습니다. 단, 휴대폰 설정에 따라 Google 음성 인식 서비스가 쓰일 수 있습니다. 이 경우 처리는 Google과 이용자 사이의 약관을 따릅니다 |
| 음식·포장 사진 | 휴대폰 안에서 글자와 바코드만 읽고, 사진은 저장하지 않으며 서버로 보내지 않습니다 |
| TalkBack 사용 여부 | 휴대폰 안에서 화면 낭독 방식을 고르는 데만 씁니다 |
| 오프라인 기록 | 인터넷이 끊겼을 때 휴대폰 안 암호화된 저장소에 잠시 두었다가 연결되면 서버로 보냅니다 |

| 권한 | 필수·선택 | 이유 | 거부하면 |
|---|---|---|---|
